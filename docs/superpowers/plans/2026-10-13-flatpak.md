# Flatpak Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship `io.github.xb00tt.debrid_applet` as a Flatpak on the freedesktop runtime: a manifest in the repo, a "flatpak" install mode in the code with graceful degradation where the sandbox blocks a feature, a local build that passes Flathub's linter, and the submission steps.

**Architecture:** The code gains one mode (`IN_FLATPAK`) and two helpers (`host_cmd`, `host_which`) that every host-program launch goes through; inside the sandbox they route via `flatpak-spawn --host` and fall back (browser, built-in wget) when that is refused. The icon name inside the sandbox is the app id, which Flatpak exports to the host. The manifest builds PyGObject and the Ayatana tray stack, vendors `requests` and `defusedxml`, and installs the desktop file, icon and metainfo under the app id itself. The self-updater is off in flatpak mode; autostart goes through the Background portal with a one-time fallback notice.

**Tech Stack:** flatpak-builder via `org.flatpak.Builder` (no root), `org.freedesktop.Platform//26.08`, PyGObject 3.58.1 (meson), `flathub/shared-modules` libayatana-appindicator, `flatpak-pip-generator`, `flatpak-builder-lint`, Python `yaml` for the manifest test. Tests: `python3 test_debrid_api.py`.

**Spec:** `docs/superpowers/specs/2026-10-13-flatpak-design.md`

**Execution:** Native (chosen by the user). Final whole-branch review on `opus`. No other agents.

## Review Focus

1. `flatpak-spawn --host` refused (no exception yet, or a locked-down install): `host_which` must return `None` within its 5 s timeout and never raise, so Play and auto-download degrade instead of crashing. Pinned in Task 1's test (patched `subprocess.run` raising and returning non-zero).
2. Notifications and the indicator inside the sandbox must use the exported icon name, or the panel shows a blank icon. Pinned in Task 1's test (`icon_name(in_flatpak)`), checked by eye in Task 5.
3. Config shared with a deb install: inside the sandbox `~/.config/debrid-applet/config.json` must be the file the deb wrote. Checked in Task 5 (keys present without re-entering).
4. Autostart portal without a backend (Mint): exactly one notification, ever, and the config flag set. Pinned by `autostart_asked` in Task 3's test; checked in Task 5.
5. Manifest permission drift: a later edit adding `--filesystem=home` or a wildcard talk-name would fail Flathub review. Pinned in Task 4's test.

```python
_host_which_cache = {}


def host_cmd(argv, in_flatpak=None):
    """argv for a program that lives on the host: unchanged outside the sandbox, flatpak-spawn --host inside
    (needs --talk-name=org.freedesktop.Flatpak; without it the spawn exits non-zero and the callers degrade)."""
    if IN_FLATPAK if in_flatpak is None else in_flatpak:
        return ["flatpak-spawn", "--host", *argv]
    return list(argv)


def host_which(name, in_flatpak=None, run=subprocess.run):
    """Path of name on the host, or None. Inside the sandbox this asks the host's `which` through flatpak-spawn with a
    5 s cap; a refused portal call, a timeout or a missing flatpak-spawn all mean None. Cached per name."""
    sandboxed = IN_FLATPAK if in_flatpak is None else in_flatpak
    if not sandboxed:
        return shutil.which(name)
    if name not in _host_which_cache:
        try:
            r = run(host_cmd(["which", name], in_flatpak=True), capture_output=True, text=True, timeout=5)
            _host_which_cache[name] = r.stdout.strip() if r.returncode == 0 and r.stdout.strip() else None
        except (OSError, subprocess.SubprocessError):
            _host_which_cache[name] = None
    return _host_which_cache[name]


def download_tool(have_aria2c):
```

```python
def browser_fallback(player, custom, in_flatpak):
    """Inside the sandbox with no reachable host player and no custom command, Play hands the stream to the browser."""
    return in_flatpak and not player and not custom


AUTOSTART_FALLBACK = ("Autostart is not available through your desktop's portal",
                      f'Add "{FLATPAK_RUN}" to your startup applications.')


def request_autostart(on_result):
    """Ask the Background portal to start the app at login (flatpak only). on_result(True/False) runs on the main
    loop; any D-Bus error counts as False. The Response arrives as a signal on the request handle, so the
    subscription is made before the call and the handle token is chosen here."""
    try:
        bus = Gio.bus_get_sync(Gio.BusType.SESSION, None)
        token = f"debrid{secrets.token_hex(4)}"
        sender = bus.get_unique_name()[1:].replace(".", "_")
        handle = f"/org/freedesktop/portal/desktop/request/{sender}/{token}"

        def on_response(_c, _s, _p, _i, _sig, params):
            code, results = params.unpack()
            bus.signal_unsubscribe(sub)
            on_result(code == 0 and bool(results.get("autostart")))
        sub = bus.signal_subscribe("org.freedesktop.portal.Desktop", "org.freedesktop.portal.Request", "Response",
                                   handle, None, Gio.DBusSignalFlags.NONE, on_response)
        opts = {"handle_token": GLib.Variant("s", token),
                "reason": GLib.Variant("s", "Keep the tray icon and the watch folder, RSS and auto-download running after login"),
                "autostart": GLib.Variant("b", True),
                "commandline": GLib.Variant("as", ["debrid-applet"])}
        bus.call(
            "org.freedesktop.portal.Desktop", "/org/freedesktop/portal/desktop", "org.freedesktop.portal.Background",
            "RequestBackground", GLib.Variant("(sa{sv})", ("", opts)), None, Gio.DBusCallFlags.NONE, 10000, None,
            lambda b, res: _finish_call(b, res, on_result, sub))
    except GLib.Error as e:
        log_event("", f"Autostart portal: {e}", "error")
        on_result(False)


def _finish_call(bus, res, on_result, sub):
    try:
        bus.call_finish(res)
    except GLib.Error as e:  # no backend (Cinnamon), or the portal refused outright: the Response never comes
        bus.signal_unsubscribe(sub)
        log_event("", f"Autostart portal: {e}", "error")
        on_result(False)
```
